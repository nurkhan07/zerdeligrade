# ZerdeliGrade: состояние (14.10.2026)

Все 8 фаз выполнены. Подробности, установка и деплой описаны в [README.md](README.md).

## Проверено
- `npm test`: 80 тестов в 7 файлах. RLS и функции БД на настоящем PostgreSQL 17 (PGlite), OMR на синтетических фото, совпадение баллов SQL и TS, CSV, коды бланков, роли, словари kk/ru, PDF.
- `npm run typecheck`, `npm run lint`, `npm run build` (35 маршрутов) проходят без ошибок.
- В браузере (без Supabase): защищённые страницы перенаправляют на `/login`, API без сессии отвечает 401, страница `/setup`, переключатель kk/ru, ошибка формы входа, мобильная ширина.

## Не проверено (нужен проект Supabase)
- Работа с настоящими данными: вход, приглашения по почте, загрузка в Storage, подписанные ссылки, экраны с данными.
  Порядок проверки: README → «Чек-лист приёмки».
- Пороги OMR на настоящих фото с телефонов (проверены только на синтетических). Нужны 30–50 реальных бланков.

## Возможные следующие шаги
- Создать проект Supabase, `npx supabase db push`, назначить первого администратора ГО, `npm run db:seed-demo`.
- Настроить SMTP для писем-приглашений.
- По результатам пилота подстроить `THRESHOLDS` в `src/lib/omr/recognize.ts`.
- Отдельная функция (вне объёма): оценка развёрнутых и рукописных ответов (OCR/vision + рубрика).
